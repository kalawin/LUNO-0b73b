# 💡 คู่มือและ Prompt สำเร็จรูปสำหรับปรับปรุง UI (UI Prompt Guide)

> **สำหรับเพื่อนร่วมงาน:** คู่มือฉบับนี้จัดทำขึ้นเพื่อให้คุณสามารถนำข้อความ Prompt ด้านล่างไป Copy แล้ววางสั่ง AI (เช่น Claude, Gemini, Antigravity, หรือ Cursor) เพื่อให้ AI ช่วยปรับแต่งหน้าตา UI ของ Luno ให้ออกมาสวยงาม มีระดับ และตรงใจได้ทันที โดยที่คุณไม่ต้องเขียนโค้ดเองครับ!

---

## 🧭 วิธีใช้งาน (3 ขั้นตอนง่ายๆ)

1. เลือกชุด Prompt ด้านล่างตามหน้าที่คุณต้องการปรับปรุง
2. **Copy ข้อความในกรอบ** ทั้งหมด
3. วางลงในช่องแชตกับ AI แล้วกดส่งได้เลย!

---

## 🌟 ชุดที่ 1: ปรับโฉมภาพรวม ธีมสี และหน้าแรก (แนะนำให้เริ่มอันนี้ก่อน)

```markdown
ช่วยอ่านแนวทางจากไฟล์ `docs/UI_DIAGNOSIS.md` ในโปรเจกต์นี้ แล้วดำเนินการปรับปรุง UI ใหม่ให้สวยงาม สง่างาม น่าเชื่อถือ สำหรับผู้บริหารสถานศึกษา (Executive Academic Theme) โดยมีข้อกำหนดดังนี้:

1. แก้ไข `src/index.css` และ Theme ให้เปลี่ยนจากโทนสีดำ-แดงมืด สู่ Deep Royal Navy (#0b0f19 ถึง #111827) ผสมสีทอง Champagne Gold และมีจุดเน้นสีน้ำเงินคราม Sapphire Indigo
2. ปรับขนาดตัวอักษรให้อ่านง่าย สบายตาสำหรับผู้บริหารอายุ 45–60 ปี (Age-friendly Typography) ใช้ฟอนต์ Prompt สำหรับหัวข้อ และ Sarabun สำหรับเนื้อหา
3. ปรับปรุงหน้า `Navbar.tsx` และ `LoginScreen.tsx` ให้มีสไตล์ Glassmorphism เรียบหรู การ์ดมีความโค้งมนสวยงาม ไม่ใช้เส้นขอบหนาเตอะ
4. นำ `framer-motion` ที่มีอยู่ในโปรเจกต์มาใส่ลูกเล่น Animation ตอนโหลดหน้าจอและตอนเอาเมาส์ชี้ปุ่มอย่างนุ่มนวล
5. ตรวจสอบให้แน่ใจว่าระบบยังคงเชื่อมต่อกับ Google Apps Script และดึงข้อมูลเนื้อหาจากโฟลเดอร์ `1_EDIT_CONTENT_HERE/` ได้ตามปกติ ไม่ให้กระทบ Logic เดิม
```

## 🚀 ชุดที่ 2: ปรับแต่งกิจกรรมจำลอง Interactive ทั้ง 4 ด่าน

```markdown
ช่วยอ่านไฟล์ `docs/UI_DIAGNOSIS.md` แล้วปรับแต่ง UI ของกิจกรรมจำลองสถานการณ์ใน `src/components/Level1Interactive.tsx` ถึง `Level4Interactive.tsx` ให้ดูเหมือนแพลตฟอร์มพัฒนาผู้นำระดับสากล:

1. ด่าน 1 (สื่อสารดิจิทัล): ทำพื้นที่วางการ์ด (Drop zones) ให้มีมิติที่ชัดเจน มองออกง่ายว่าตรงไหนวางได้ มีสถานะ Hover และแอนิเมชันตอนปล่อยการ์ดลงกล่อง
2. ด่าน 2 (ความคุ้มค่า ROI): เปลี่ยนหน้าตารางคำนวณให้เป็นการ์ด Metrics ทางการเงินแบบ Dashboard มีตัวเลขเปรียบเทียบที่เด่นชัด สวยงาม
3. ด่าน 3 (กรณีศึกษาครูมาลี): ปรับแต่งกล่องบทสนทนาสถานการณ์และตัวเลือก 3 ทาง ให้เหมือนการเล่น Role-Play บทบาทสมมติของผู้นำ มีการ์ดสรุปข้อคิดอย่างสง่างาม
4. ด่าน 4 (Vision Builder): เปลี่ยน Dropdown ดำๆ ธรรมดา ให้เป็นการ์ดเลือกองค์ประกอบวิสัยทัศน์ที่พรีเมียม และมีกล่องแสดงคำแถลงวิสัยทัศน์ที่เปล่งประกาย (Gold Gradient Glow)
5. รักษาการเชื่อมต่อข้อมูลกับไฟล์ `1_EDIT_CONTENT_HERE/interactive_scenarios.ts` ไว้อย่างสมบูรณ์
```

## 🎓 ชุดที่ 3: ปรับปรุงหน้าทำข้อสอบ และใบวุฒิบัตร (Certificate)

```markdown
ช่วยอ่านไฟล์ `docs/UI_DIAGNOSIS.md` แล้วปรับปรุงหน้า `QuizView.tsx` และ `CertificateView.tsx` ให้ได้มาตรฐานวิชาการ:

1. หน้าทำข้อสอบ (QuizView): ทำแถบ Progress Bar นุ่มนวล ช้อยส์คำตอบขนาดใหญ่ กดง่ายด้วยนิ้วหรือเมาส์ มีไฮไลต์เวลาเลือกที่ชัดเจน
2. หน้ารายงานผลและเกียรติบัตร (CertificateView):
   - ปรับสไตล์กราฟ Radar Chart และ Bar Chart ใน Chart.js ให้ใช้โทนสีทอง-น้ำเงินหรูหรา ตัวหนังสือคมชัด
   - แยกสไตล์บนหน้าจอ (โชว์การ์ดวุฒิบัตรหรูหรา มีลายน้ำ) ออกจากสไตล์การสั่งพิมพ์ (`@media print`)
   - เมื่อกดพิมพ์ลงกระดาษ A4 จริง ให้พื้นหลังเป็นสีขาว กรอบเกียรติยศสีทอง/น้ำเงินราชการ ประหยัดหมึกพิมพ์ และดูเป็นวุฒิบัตรทางการที่นำไปแนบผลงานวิชาการได้จริง
```
