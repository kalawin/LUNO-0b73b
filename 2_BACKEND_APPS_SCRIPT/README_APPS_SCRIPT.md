### 📋 วิธีอัปเดตโค้ดไปยัง Google Apps Script (เมื่อมีการแก้ไข Code.gs)
1. เปิดไฟล์ `Code.gs` ในโฟลเดอร์นี้ แล้วกด **Ctrl+A / Cmd+A** เพื่อคัดลอกโค้ดทั้งหมด
2. เปิดลิงก์ **Google Apps Script Editor** ด้านบน
3. วางโค้ดทับในหน้าจอ Apps Script แล้วกดไอคอน **บันทึก (แผ่นดิสก์)** 💾
4. กดปุ่มสีน้ำเงิน **การทำให้ใช้งานได้ (Deploy)** ➔ **จัดการการทำให้ใช้งานได้ (Manage deployments)**
5. กดไอคอน **ดินสอ (แก้ไข)** ➔ เลือกเวอร์ชัน **"รุ่นใหม่" (New version)** ➔ กด **ทำให้ใช้งานได้ (Deploy)**
